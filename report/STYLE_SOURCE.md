# AAAI 2024 style provenance

`aaai24.sty` and `aaai24.bst` are unmodified copies from the AAAI 2024
camera-ready author kit mirrored in:

https://github.com/guicho271828/aaai-template/tree/fb69579bdd4e0143671929fdcdca5b37bd998d20/authorkits/AuthorKit24/CameraReady/LaTeX

The assignment's official landing page is https://aaai.org/authorkit24-2/.
That site returned a proxy HTTP 403 in the current environment, so the
fixed-commit public mirror was used. This is a third-party mirror, not an
independent verification against the currently hosted official archive.
The original style headers, notices, dimensions and font sizes are retained.
The report uses the author kit's required preamble and does not override layout.
